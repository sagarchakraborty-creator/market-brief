# Market Brief

A daily Indian financial news bulletin from Economic Times, Moneycontrol, Business Standard and Livemint, written to be heard. The app reads it aloud with your phone's own voices.

**Open it:** https://sagarchakraborty-creator.github.io/market-brief/

- **Android (Chrome):** tap Install in the app, or ⋮ → Install app.
- **iPhone (Safari):** Share → Add to Home Screen.

A new bulletin is added to `briefs/` every morning at 7:30 AM IST. Each bulletin is an original spoken summary that links to the source articles.
